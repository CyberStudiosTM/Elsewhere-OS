## 💌 ୨୧ you've got a message!

remember when logging onto the internet felt exciting?

## ☁️ what is elsewhere messenger?

Elsewhere Messenger is a retro-inspired desktop application with a modern development direction and a distinctly early-2000s personality.

its visual identity is rooted in **Elsewhaero**, a dreamy combination of Frutiger Aero, nostalgic software interfaces, and the soft, optimistic internet aesthetic of the 2000s.

the goal is to create a messaging experience that feels familiar without simply reproducing an old program.

something nostalgic, customizable, playful, and uniquely Elsewhere.

---

## 🫧 the elsewhere experience

### ✧ classic internet nostalgia

the project's design direction includes:

- personalized buddy lists and contact experiences
- nostalgic messaging windows
- status messages and display customization
- playful interactions inspired by classic messengers
- customizable interface appearances
- companion creative tools

features are developed in stages, and beta functionality may differ from the full design scope.

### 🎀 make it yours

Elsewhere is designed around the idea that a messaging app should feel like *your* space.

the longer-term vision includes expressive themes, personalized windows, and decorative little details that make the interface feel less like a utility and more like a place to spend time.

### 💿 old-school personality, modern development

Elsewhere draws inspiration from classic desktop messengers while evolving as its own application.

modern integrations, account functionality, and additional creative features are being investigated and developed independently.

not every planned integration is available in the public beta.

a *lot* has happened since v0.2.21. ♡

> **✦ fresh in v0.2.54: profiles, all grown up!** make **multiple pages** with page menus, popups and click/hover interactions; build or install **widgets** in the Widgets Studio (a pocket pet, music player, terrarium, mini-game and more), plus **polls** and a **visitor counter**; organize pictures in the **Asset Manager** with a Sprite Sheet Studio; hang out in your private **Elsewhere Home** with discovery and **webrings**; and share layouts, widgets, skins and art in the **Creative Exchange** and **Community Showcase**. every profile also gets a short link: `cyberthreed.github.io/CyberStudios/@you` ♡
>
> **✦ v0.2.53: 🧠 Algorithmic Intelligence!** just *say what you want* ("sparkly pink heading and falling hearts") and get real HTML, CSS and JavaScript for your profile, with a live preview and one-click insert. it fixes typos, reads colors and numbers, and is honest about what it doesn't know. *the elsewhere code generator runs on a rule-based algorithm designed by Cyber. no data sets, no AI generation, no generative slop. it runs right on your computer: just code, functions, and vibes ♡*
>
> **✦ v0.2.52: Profile Workshop!** design your profile like a real little website. the **Visual Designer** lets you drag, resize, rotate, layer and style everything (gradients, shadows, cute animations), with snapping guides, undo and a phone preview. add **code blocks** with your own HTML, CSS and JavaScript (safely sandboxed), roll a starter page with the **Layout Generator** (no AI, just hand-made vibes ♡), check your page with **View as** a friend or the public, and bring back older looks with **version history**.
>
> **✦ v0.2.51:** **Edit My Profile** now knows you're signed in, your profile options live in the **File** menu, and Web Treasures no longer shows file names (creators are still credited ♡).
>
> **✦ v0.2.50:** profiles got their glow-up. the **Elsewhere Original** layout now sits on the real Elsewhere desktop wallpaper (rolling hills, rainbow, bubbles) with frosted glass panels and glossy headers, and **Classic Profile** gets glossy title bars too. in **Creative Studio**, click a treasure to **preview it before placing**, previews always show the whole picture, and new layers start unnamed with no file names on hover. ♡

### 🦋 elsewhere profiles

your own little homepage, the way profiles used to feel ♡ pick a **Classic Profile** two-column page or the glossy **Elsewhere Original**, then make it yours with Quick Customize: colors, fonts, patterns, a profile picture and banner, mood, status, about me, interests, a profile song, **Top Friends**, a **guestbook** and **bulletins**. choose who can see it (everyone, friends, or only you), and anyone can visit it on the web without installing anything.

**File → My Profile…** · **File → Edit My Profile… → ✦ Visual Designer**

### 🎨 creative studio

a blank canvas for making anything: collages, stationery, little graphics and decorated photos, with 9 tools, a **Camera Booth** for photos and photo strips, **My Gallery**, and a **Skin Wardrobe** of 23 workspace looks.

**Activities → Creative Studio…**

### ✿ pixel doll studio (beta)

a layered dress-up studio for pixel dolls: bodies, skin tones, poses, hair, makeup, clothes and accessories, all stacked in proper layers. save your dolls, export crisp PNGs, or send them to Creative Studio.

*the doll art is still being drawn, so the beta uses simple placeholder shapes for now.*

**Activities → Pixel Doll Studio…**

### 💅 skins & skinmapper (beta)

- design your own Messenger skin in **SkinMapper** and share it as an `.eskin` file
- wear official skins straight from **Tools → Skins**, sorted into collections: **Neapolitan Dream**, **Mint Choco Diary**, the dark-glass **Frutiger Evil**, **Windows 7** and the **Elsewhaero Signature** collection
- a skin dresses *every* part of Messenger: sign-in, chats, menus, pickers and Web Treasures

### 💬 chatting

group chats, photos and GIFs, online / away / busy status, **typing…**, unread counts, and per-contact colors for Instagram contacts (right-click a contact).

### 🌐 web treasures

the old Winks button is now **Web Treasures**, with the Elsewhere Collection and your own **My Treasures** shelf. every graphic credits its creator.

for every detail, see the release notes:

## 📥 download & installation

### ୨୧ Windows x64

**Current documented beta: v0.2.54**

[**☁️ Download Elsewhere Messenger Setup**](https://github.com/CyberStudiosTM/Elsewhere-OS/releases/download/messenger-v0.2.54/Elsewhere-Messenger_0.2.54_x64-setup.exe)

### ୨୧ macOS (Apple Silicon & Intel)

the Mac build is **free and unsigned**: grab `Elsewhere-Messenger_<version>_macOS_universal.dmg` from the [latest release](https://github.com/CyberStudiosTM/Elsewhere-OS/releases/latest). the first time you open it, **right-click the app → Open** so macOS lets it run.

### ✧ getting started

1. Download the Windows x64 setup file from the GitHub release.
2. Run the installer and follow its installation prompts.
3. Launch Elsewhere Messenger.
4. For future releases, use the automatic update system or **Help → Check for Updates**.

**Please note:** Elsewhere Messenger is beta software. Features may change, and occasional issues are possible.

already on v0.2.21 or newer? updates arrive automatically. automatic updates aren't a guarantee that every future update will install successfully on every system.
